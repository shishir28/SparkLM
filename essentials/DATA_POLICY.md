# Data Policy

## Current status

No training dataset has been selected yet.

## Rules

- Do not commit raw, interim, or processed data.
- Do not commit confidential, personal, tenant-identifying, or unlicensed data.
- Keep raw data local or externally mounted.
- Record the source, licence or usage permission, date, and preprocessing steps for every dataset used.
- Prefer small, well-documented, public, or explicitly approved corpora.
- Remove or avoid any private identifiers before data enters the project.

## Future dataset notes

For each dataset, add:

- name
- source
- licence / usage permission
- date obtained
- privacy review
- preprocessing summary
- intended use
