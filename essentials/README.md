# Essentials

This folder contains the project foundations needed before model implementation begins.

Suggested contents:

- `ENVIRONMENT.md` — Python, PyTorch, CUDA, GPU, storage, and memory details.
- `DATA_POLICY.md` — dataset sources, licences or usage permissions, privacy rules, dates, and preprocessing decisions.
- `SMOKE_TEST.md` — the expected output and observations from the deterministic environment/device smoke test.
- `PROJECT_RULES.md` — learning-path constraints, reproducibility conventions, and experiment discipline.

Keep machine-specific secrets and private data out of this repository. Use this folder for concise, version-controlled notes that make the work reproducible.
